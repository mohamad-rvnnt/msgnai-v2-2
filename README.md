# MSGN AI v2.2

MSGN AI نسخه ۲.۲ یک دستیار هوش مصنوعی شخصی، پیشرفته، مجهز به حافظه دائمی، ابزار مدیریت فایل، تحلیل کدهای برنامه‌نویسی، تولید تصویر و قابلیت‌های یکپارچه با تلگرام است.

## ویژگی‌ها
- 🧠 **حافظه دائمی و پایگاه داده** (SQLite)
- 📁 **مدیریت پیشرفته فایل‌ها و پشتیبان‌گیری خودکار**
- 🤖 **ربات تلگرام کاملاً فعال** (پشتیبانی از ارسال و دریافت فایل، اسناد و تصاویر)
- 🎨 **تولید تصویر**
- 🔍 **تحلیل هوشمند پروژه‌ها و کدهای برنامه‌نویسی**

## ساختار پروژه
- `msgnai_v2-2.py` - هسته اصلی برنامه
- `telegram_bot.py` - مدیریت ارتباط با تلگرام
- `file_manager.py` - مدیریت فایل‌ها
- `image_generator.py` - ماژول تولید تصویر
- `project_intel.py` - تحلیلگر پروژه
- `database/` - پایگاه داده سیستم

## نصب و راه‌اندازی
1. مخزن را کلون کنید:
   ```bash
   git clone <url>
   ```
2. متغیرهای محیطی تلگرام را تنظیم کنید:
   ```bash
   export TELEGRAM_BOT_TOKEN="your_token"
   export TELEGRAM_CHAT_ID="your_chat_id"
   ```
3. برنامه را اجرا کنید:
   ```bash
   python3 msgnai_v2-2.py
   ```
