# ✨ Morse Code CLI Tool

یک ابزار خط فرمان (CLI) بسیار زیبا، رنگارنگ و مجهز به ایموجی برای رمزگذاری متن به کد مورس و رمزگشایی کد مورس به متن. 

ساخته شده با ❤️ توسط **[@m_sgn](https://t.me/m_sgn)**

---

## 🌟 ویژگی‌ها
- 🎨 محیط گرافیکی ترمینالی با رنگ‌بندی جذاب ANSI
- ⚡ استفاده از ایموجی‌ها و منوی تعاملی شیک و کاربرپسند
- 🔄 قابلیت تبدیل دوطرفه: متن ➔ مورس و مورس ➔ متن
- 🚀 قابلیت نصب سریع و اجرای سراسری با دستور `morse` در ترموکس یا لینوکس
- 📦 قابلیت کلون کردن آسان از گیت‌هاب

---

## 📥 آموزش نصب و راه‌اندازی (Git Clone & Setup)

برای نصب و استفاده از این ابزار در ترموکس یا سیستم لینوکسی خود، دستورات زیر را به ترتیب اجرا کنید:

1. **کلون کردن مخزن گیت‌هاب:**
   ```bash
   git clone https://github.com/m-sgn/morse-cli.git
   cd morse-cli
   ```

2. **اعطای دسترسی اجرایی به اسکریپت:**
   ```bash
   chmod +x morse_tool.py
   ```

3. **تنظیم دستور سراسری (`morse`) در ترمینال:**
   برای اینکه بتوانید در هر مسیری در ترموکس یا ترمینال با نوشتن کلمه `morse` اسکریپت را اجرا کنید:
   ```bash
   # برای ترموکس یا لینوکس
   mkdir -p ~/../usr/bin/
   cp morse_tool.py ~/../usr/bin/morse
   chmod +x ~/../usr/bin/morse
   ```
   *(یا در فایل تنظیمات شل خود مثل `~/.bashrc` یا `~/.zshrc` یک الیاس (Alias) قرار دهید:)*
   ```bash
   alias morse="python3 $(pwd)/morse_tool.py"
   ```

## 🎮 نحوه استفاده
پس از نصب، کافی است در هر جای ترمینال دستور زیر را وارد کنید:
```bash
morse
```

منوی تعاملی باز شده و می‌توانید بین حالت‌های زیر انتخاب کنید:
1. **تبدیل متن به کد مورس** (مثلاً: `HELLO` ➔ `.... . .-.. .-.. ---`)
2. **تبدیل کد مورس به متن** (مثلاً: `.... . .-.. .-.. ---` ➔ `HELLO`)
